# VRM Color Editor

ブラウザだけで動く、VRMモデル用のWebアプリです。インストールは不要です。

## 使ってみる
👉 https://neoujiny.github.io/VRM-Color-Editor/

## 主な機能
- VRMモデルの読み込みとプレビュー
- VRMモデルの色彩編集&ペイント&スタンプ機能
- VPOファイルによるパーツの追加&スプリングボーン編集機能
- VRMAアニメーションのプリセット再生
- 鑑賞モード（ステージGLBの読み込み、ライトの切り替え）
- ムービー書き出し（MP4 / 1920×1080 / 30fps）
- その他、未曾有の編集機能

## 使い方のヒント
- アニメーションやMToonシェーダーのUVスクロールを確認するときは、VRMを読み込んでからプレビューを「再生モード」にしてください。
- 鑑賞モードは画面左メインメニューに並ぶのVRMAタブの中にあります。
- 鑑賞モードのメニューは「W」キーで表示されます。鑑賞モードを終える時は「esc」キーを押します。鑑賞モードで読み込めるステージGLBは1つだけです。後から読み込むと置き換わります。（近日、複数のGLBを配置可能にする予定）
- 鑑賞モードのメニュー内にMP4書き出しボタンがあります。

## プライバシー
読み込んだモデルやファイルは、お使いのブラウザの中だけで処理されます。どこかのサーバーに送られることはありません。

## 動作環境
WebGLが使えるブラウザ（Chromeを推奨）
パソコン推奨（スマホでも動く可能性はありますが、画面が狭すぎて厳しいと思われます。）
